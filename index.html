Data base

This model uses the supplied South Downtown parcel/building cross-reference as its geographic base. City of Atlanta tax parcels provide the parcel polygons and attributes; OpenStreetMap provides building footprints and mapped building levels/heights. The existing city is the baseline for future experiments.

Navigation

Left drag rotates. Right drag pans. Scroll zooms. Click a parcel to select it. Click a building to select the parcel it intersects. The geometry stays geographically consistent because all features use the same lat/lon coordinate frame.
